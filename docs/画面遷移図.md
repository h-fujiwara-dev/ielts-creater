```mermaid
flowchart TD
    S01[S-01 ログイン/サインアップ画面] -->|ログイン成功| S02[S-02 問題生成画面]
    S02 -->|生成完了・開始| S03[S-03 回答画面]
    S03 -->|提出| S04[S-04 結果画面]
    S04 -->|再挑戦| S02
    S02 -.ナビゲーション.-> S05[S-05 履歴一覧画面]
    S02 -.ナビゲーション.-> S06[S-06 ダッシュボード画面]
    S05 -->|過去の受験を選択| S04
    S06 -.ナビゲーション.-> S02
```

各画面の詳細（主要要素・主な操作）は[frontendリポジトリ docs/画面設計書/](https://github.com/h-fujiwara-dev/ielts-creater-frontend/blob/main/docs/画面設計書/)を参照。
