# Icon attribution

The service icon glyphs used in `../aws-infra.drawio` / `../aws-infra.svg` are
sourced from [Simple Icons](https://simpleicons.org) (CC0 1.0) and colorized to each
service's official brand hex per Simple Icons' own brand data.

| Service  | Hex       |
| -------- | --------- |
| Vercel   | `#000000` |
| Supabase | `#3FCF8E` |
| OpenAI   | `#000000` |

These `.svg` files are the human-editable source. The `.drawio` file embeds
percent-encoded copies of them directly in each node's style so it stays
self-contained and doesn't depend on external files to render or export.

Brand marks remain trademarks of their respective owners; they are used here
only to identify the services integrated into this project's architecture.
