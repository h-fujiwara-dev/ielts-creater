#00065

Cognito Hosted UI デザイン改善案

Cognito Hosted UI（Classic）本体（frontendの/login中間ページではなく、実際の認証フォーム画面）を対象にしたデザイン改善案。 左右の枠内はそれぞれ独立したHTMLページを<iframe>で表示しており、Afterは本チケットが提案する cognito-hosted-ui.proposal.cssをそのまま読み込んでいる（モックアップと提案CSSに差分がない）。

見出し・ラベル等はAfter側で日本語表記に変更している。ただし実際のCognito Hosted UI本体（Classic）でこれを実現する技術的手段は 確立できていない（ui_localesパラメータは実機検証で無効、CSSでの文言差し替えも不可）。あくまで理想形のデザイン提案であり、 実現可否の検証は後続の実装チケットの課題とする（詳細はチケット本文参照）。

Before（#00052時点の現状）

After（本チケットの改善案）

主な変更点

  • ロゴ画像を追加（.logo-customizable、空白バナーの解消）
  • 入力欄（.inputField-customizable）にボーダー・角丸・フォーカス時のリングを追加
  • 「パスワードをお忘れですか？」「新規登録」リンク（.redirect-customizable）をブランドカラー（濃いオレンジ）に変更
  • エラー表示（.errorMessage-customizable）にアプリ本体の--color-error系トークンを適用
  • カード自体（.background-customizable）にoverflow: hidden付きの角丸・影を追加し、紺色バナーと白いフォーム部分の角を統一（アプリ本体の.cardコンポーネントに近づける）
  • 見出し・ラベル・ボタン・リンク・エラー文言を日本語表記に変更（実現可否は要検証、モックアップ上の提案）
  • 送信ボタンの文字色を白→ネイビーに変更、リンク色を濃いオレンジに変更し、コントラスト比をWCAG AA基準（4.5:1）まで改善
  • ラベル・見出し・入力欄等のフォントスタックをシステムフォントで統一（外部Webフォントは読み込み不可のため）
