# 開発フェーズとの対応

- 文書種別: ロードマップ
- 対象プロジェクト: IELTS Creator（IELTS練習問題作成アプリ／ポートフォリオ用途）
- 更新日: 2026-08-09
- 関連文書: [業務要件定義書 7章 マイルストーン](./業務要件定義書.md#7-マイルストーン開発フェーズ) / [システム要件定義書 8章 アーキテクチャ](./システム要件定義書.md#8-アーキテクチャ)

各フェーズで、どのリポジトリ・ドキュメントが対応範囲になるかを整理する。

| フェーズ | 対応する範囲 |
| --- | --- |
| Phase 1 | frontend: 画面設計一式（[docs/画面一覧.md](https://github.com/h-fujiwara-dev/ielts-creater-frontend/blob/main/docs/画面一覧.md), [docs/画面設計書/](https://github.com/h-fujiwara-dev/ielts-creater-frontend/blob/main/docs/画面設計書/)。新設のTop画面（S-01_Top画面.md）を含む）/ backend: ER図・API一覧・OpenAI/Polly連携（[docs/ER図・テーブル定義.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/ER図・テーブル定義.md), [docs/API一覧.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API一覧.md), [docs/API設計書/POST_question-sets.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API設計書/POST_question-sets.md)）。AWSインフラは未使用（StorageServiceはローカル実装） |
| Phase 2 | backend: Cognito連携（[docs/API一覧.md 3章 認証フロー](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API一覧.md#3-認証フロー)）/ frontend: NextAuth連携（[docs/画面設計書/S-02_ログインサインアップ画面.md](https://github.com/h-fujiwara-dev/ielts-creater-frontend/blob/main/docs/画面設計書/S-02_ログインサインアップ画面.md)）、[システム要件定義書 8.4章](./システム要件定義書.md#84-非機能要件の実現方式)のセキュリティ要件実現方式 |
| Phase 3 | infra: AWSインフラ構成・Terraform（[システム要件定義書 8.3章](./システム要件定義書.md#83-awsインフラ構成図) + [infraリポジトリ](https://github.com/h-fujiwara-dev/ielts-creater-infra)） |
| Phase 4 | [システム要件定義書 8.4章](./システム要件定義書.md#84-非機能要件の実現方式)の運用・保守性要件（監視）、ダッシュボード機能の拡充（frontend/backend双方） |
