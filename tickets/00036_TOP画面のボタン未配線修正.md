- 対象リポジトリ: frontend
- ステータス: 完了

- 関連ドキュメント: [#00010 TOP画面のfrontend実装](./00010_TOP画面のfrontend実装.md) / [#00012 TOP画面のreactbits演出強化](./00012_TOP画面のreactbits演出強化.md) / [#00018 ログインサインアップ画面のfrontend実装](./00018_ログインサインアップ画面のfrontend実装.md)

## 実現すること

TOP画面（S-01）で複数のCTAボタンが機能していないという報告を受け、`src/app/page.tsx`が描画する全セクション（SiteHeader/Hero/TrustBand/Story/FeatureGrid/TwoColCta/CtaBand/Insights/SiteFooter）を調査した結果、共通の原因による未配線バグが複数箇所で見つかった。

`src/components/ui/button.tsx`の`Button`はBase UIのpolymorphicコンポーネントで、`render={<Link href=.../>}`を渡すか`onClick`を渡さない限り、ただの`<button type="button">`としてクリックしても何も起きない。`SiteHeader`のCTAのみ[#00018](./00018_ログインサインアップ画面のfrontend実装.md)実装時に`/login`へのLink配線が追加されたが、それ以外のセクションの同一文言ボタンへの追従が漏れており、リグレッションではなく「実装時の配線し忘れが横展開されずに残っている」状態である。

既存のVitestテストは「ボタンが描画されているか」のみを検証しており、クリック時の遷移・href有無を検証していないため、今回のような未配線バグを検出できない構成になっている。

修正対象:

1. Hero/Story/FeatureGrid/CtaBandの「無料ではじめる」「ログイン」ボタン計8箇所（`hero.tsx:35-49` / `story.tsx:19-31` / `feature-grid.tsx:50-62` / `cta-band.tsx:24-36`）に`/login`へのLink配線を追加する
2. TwoColCtaの「使い方を見る」ボタン（`two-col-cta.tsx:23-29`）に`#how-it-works`（`insights.tsx`の`id="how-it-works"`）へのアンカースクロールを追加する
3. TwoColCtaの「よくある質問を見る」ボタン（`two-col-cta.tsx:47-54`）はリンク先のFAQセクション/ページ自体が存在しないため、要素ごと削除する
4. SiteFooterのソーシャルリンク（公式サイト/コミュニティ/フィード、`site-footer.tsx:34-45`、`socialLinks`定義4-8行目）は実URLが未定義の飾りボタンのため、要素ごと削除する
5. SiteHeaderのロゴ（`site-header.tsx:25-28`）を`Link href="/"`にする（`auth-header.tsx:8-14`では既に同ロゴがLink実装済みで、実装に不整合がある）
6. 「無料ではじめる」ボタン経由で`/login`へ遷移した際、`LoginSignupFlow`（`login-signup-flow.tsx:12`）が常に`useState<FlowStep>("login")`で初期化されておりサインアップフォームへの導線が弱いため、クエリパラメータ等でstep初期値を制御できるように改善する
7. 再発防止として、主要CTAのクリック時の遷移先（href/onClick発火）を検証するテストを追加する
