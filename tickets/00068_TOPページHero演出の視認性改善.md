# #00068 TOPページHero演出の視認性改善

- 対象リポジトリ: frontend
- ステータス: 完了
- type: fix
- 関連ドキュメント: [#00066 TOPページビジュアル演出のモダン化](./00066_TOPページビジュアル演出のモダン化.md) / [#00012](-) （Hero背景へのDotField/GradientMesh導入、frontendリポジトリ内チケット）

## 実現すること

[#00066](./00066_TOPページビジュアル演出のモダン化.md)で導入したTOPページHeroセクションの背景演出（`DotField`・`GradientMesh`）が、実際に確認したところ以下の点で見づらかったため、ユーザーとの対話的な確認を通じて色調整を行った。

- `DotField`のドット色がネイビー〜濃いオレンジのグラデーション（`rgba(15, 23, 42, 0.8)` 〜 `rgba(249, 115, 22, 0.5)`）で不透明度が高く、見出し・本文テキストと重なって可読性を損なっていた
- `GradientMesh`の3色ブレンドのうち1色が紺色（`#0f172a`）で、背景全体が暗く沈んだ印象になっていた
- Hero内の「ログイン」「ゲストとして始める」ボタン（`variant="outline"`）が、通常時・hover時とも背景色の変化が薄く（`hover:bg-brand-navy/5`）、ホバーしても視覚的な変化がほとんど分からなかった

対応内容:

1. `src/components/reactbits/dot-field.tsx`: デフォルトの`gradientFrom`/`gradientTo`を薄いオレンジ単色（`rgba(249, 115, 22, 0.12)` 〜 `rgba(249, 115, 22, 0.24)`）に変更し、色相をブランドオレンジに統一しつつテキストとのコントラストを確保した
2. `src/components/reactbits/gradient-mesh.tsx`: デフォルトの`colorA`を紺色（`#0f172a`）からページ背景と同系のcream（`#fffdf9`、実質無色）に変更。シェーダーのアルファ値とCSSフォールバックの`opacity`をともに`0.16`→`0.08`に下げ、背景の主張を弱めた
3. `src/components/sections/hero.tsx`: 「ログイン」「ゲストとして始める」ボタンの共通classNameを、白背景+`shadow-sm`の明確な通常状態と、hover時にラベンダー背景（`hover:bg-brand-lavender`）+ボーダー強調（`hover:border-brand-navy/40`）+影強調（`hover:shadow-md`）に変更し、状態変化を視認できるようにした

本チケットは、実装をユーザーとの対話的なビジュアル確認（`npm run dev`起動＋ブラウザでのスクリーンショット確認）を通じて先行させ、完了後に事後的にチケット化したものである（通常のチケット起票→実装の順序とは異なる）。
