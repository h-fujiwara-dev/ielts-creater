# #00055 ダッシュボードログアウト時のエラー修正

- 対象リポジトリ: infra
- ステータス: 未対応
- type: fix
- 関連ドキュメント: [#00041 ログアウト時のCognito Hosted UIグローバルログアウト対応](./00041_ログアウト時のCognitoHostedUIグローバルログアウト対応.md)

## 実現すること

dev環境での手動確認の結果、ダッシュボードでログアウトを行うとエラーが発生することが分かった。

[#00041](./00041_ログアウト時のCognitoHostedUIグローバルログアウト対応.md)で実装された`ielts-creater-frontend/src/app/api/auth/cognito-logout/route.ts`は、Cognito Hosted UIのログアウトエンドポイントへ`logout_uri=http://localhost:3000/login`（末尾`/login`パス付き）を付与してリダイレクトする。一方`ielts-creater-infra/terraform/envs/dev/terraform.tfvars`の`logout_urls`は`["http://localhost:3000"]`（`/login`パスなし）となっており、Cognito App Clientに登録された`logout_urls`と実際に送信される`logout_uri`が完全一致していない。CognitoのHosted UIログアウトエンドポイントは`logout_uri`が登録済みURLと厳密一致しない場合エラーを返すため、これが今回のエラーの原因と考えられる。[#00041](./00041_ログアウト時のCognitoHostedUIグローバルログアウト対応.md)の受け入れ条件で「実AWS環境未確認」とされていた箇所が、今回の手動テストで顕在化したものと考えられる。

対応方針:

1. `terraform/envs/dev/terraform.tfvars`の`logout_urls`を、実際に送信される`logout_uri`（`/login`パス付き）に修正する

## 受け入れ条件

- [ ] ログアウト操作でエラーが出ず、Cognito Hosted UIログアウトを経由して`/login`へ正しく遷移する
- [ ] `terraform apply`が通る
- [ ] ログアウト後に再度ログインボタンを押した際、無言でSSO再認証されないこと（#00041の未検証項目）もあわせて確認する
