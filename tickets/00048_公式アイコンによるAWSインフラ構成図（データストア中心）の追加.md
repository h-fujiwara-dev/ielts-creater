## 実現すること

現在README.mdおよびシステム要件定義書8.3のインフラ構成図はMermaidのflowchartのみで表現されている（[#00037](./00037_インフラ構成の見直し（Vercel_Supabase化）とREADME構成図の追加.md)で追加）。ポートフォリオとしての訴求力を高めるため、README.md側の構成図をAWS公式アイコン（およびVercel/Supabase/OpenAIの公式ブランドアイコン）を用いたdraw.io図に差し替える。データベース（Supabase）・ファイルストレージ（S3）・認証ストア（Cognito User Pool）といった「データストア」群を視覚的にグルーピングし、データの保持場所が一目でわかる構成図とする。

範囲は既存のMermaid構成図（8.3 AWSインフラ構成図）と同一要素（Vercel / ALB / NAT Gateway / ECS Fargate / VPC［Public Subnet・Private Subnet］/ Supabase / OpenAI API / S3 / Polly / Cognito）とし、要素を追加しない。

作図はAWS公式アイコンをdraw.ioの組み込みAWS4ステンシル（`resIcon=mxgraph.aws4.*`、画像フェッチ不要）で参照し、Vercel/Supabase/OpenAIのみ公式ブランドSVGをdata URIとして埋め込む方式で、トークン消費を抑えて作成する。
