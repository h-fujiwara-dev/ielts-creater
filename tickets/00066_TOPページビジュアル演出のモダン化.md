## 実現すること

TOP画面（S-01）は唯一の未ログイン公開画面であり、`業務要件定義書` §2.2で明記されている通り、サービス利用者向けの入口であると同時に、採用担当者・エンジニアが実装力を評価する画面という役割も担う。

現状のTOPページ（`ielts-creater-frontend` `src/app/page.tsx`）は既に`DotField`（canvas 2Dのカーソル反応パーティクル背景、Hero専用）・`SpotlightCard`（マウス追従スポットライト）・`BlurText`（文字単位blur-inアニメーション）・`RevealOnScroll`（スクロール連動フェードイン、全セクション共通）を実装済みで、いずれも`prefers-reduced-motion`に対応している。本チケットでは、この基準線をさらに超えるビジュアル/演出面の強化により、実装力をより強くアピールする。既存コンポーネント群と同様「`reactbits.dev`を参考にTypeScriptへ手動移植し、追加npm依存を増やさない自前実装」という設計哲学を踏襲する。

対象リポジトリを`root`（本チケット定義）と`frontend`（実装）の両方とするが、[#00065](./00065_CognitoHostedUIログイン画面のデザイン改善案作成.md)と同様、**本チケットのマージ後に、developを起点とした別の実装ブランチで着手する**（チケット定義と実装を同一の未マージブランチにまたがらせない運用ルールに従う）。

実装内容は以下の4点とする。

1. **Hero背景をWebGLシェーダー演出に強化**: 新規コンポーネント（`src/components/reactbits/`配下）として、生WebGL2によるアニメーションするメッシュグラデーション/オーロラ風背景を自前実装する（three.js等のライブラリは追加しない）。現在`Hero`（`src/components/sections/hero.tsx`）で`DotField`が塗っている単純な2色グラデーションをこのシェーダーに置き換え、`DotField`のカーソル反応パーティクル層はそのまま重ねて残す。画面外では`IntersectionObserver`でrAFループを停止し、`usePrefersReducedMotion`で静止グラデーションにフォールバックする。
2. **FeatureGridをBento Grid + 3Dチルト化**: `FeatureGrid`（`src/components/sections/feature-grid.tsx`）の均等3カラムgridを、非対称サイズ（大枠+標準枠混在）のbento風レイアウトに変更する。新規フック（カーソル位置に応じた`perspective`/`rotateX`/`rotateY`算出）を既存`SpotlightCard`に追加適用し、スポットライトに加えて軽い3D傾き演出を付与する。`prefers-reduced-motion`では無効化する。
3. **「Powered by」技術スタック帯の新設**: Next.js / React / AWS Cognito / OpenAI / Vercel等、実際に使用している技術ロゴをCSSのみの無限マーキー（端を`mask-image`でフェード、ホバーで一時停止、reduced-motionでは静止表示）で流す新規セクションを追加し、`TrustBand`とFeatureGridの間（または`SiteFooter`直前）に挿入する。採用担当者向けに実際の技術構成を可視化する狙い。
4. **マグネットCTAボタン**: カーソル近接時にボタンを引き寄せる（移動量は上限クランプ）新規フックを実装し、Heroおよび`CtaBand`の主要CTA（「無料ではじめる」）に適用する。タッチデバイス・reduced-motionでは無効化する。

各新規コンポーネント・フックには既存の慣習（`hero.test.tsx`等のcolocatedテスト）に倣ったvitestユニットテストを追加する。

## 受け入れ条件

- [x] Hero背景が自前実装のWebGL2シェーダーによるアニメーションするメッシュグラデーションに置き換わっており、`DotField`のカーソル反応パーティクル演出は引き続き機能している
- [x] Hero背景のアニメーションが画面外では停止し（`IntersectionObserver`）、`prefers-reduced-motion: reduce`では静止表示にフォールバックする
- [x] FeatureGridがbento風の非対称グリッドになっており、各カードに軽い3Dチルト演出が追加されている（`prefers-reduced-motion`で無効化）
- [x] 「Powered by」技術スタック帯（無限マーキー）が新設され、ホバーで一時停止・`prefers-reduced-motion`で静止表示になる
- [x] Hero・CtaBandの主要CTAボタンにマグネット演出が適用され、タッチデバイス・`prefers-reduced-motion`では無効化されている
- [x] 新規npm依存を追加していない（three.js等のライブラリは使用しない）
- [x] 375px/768px/1024px/1440pxでレイアウト崩れ・横スクロールが発生しない
- [x] キーボード操作・フォーカスリング・クリック動作が既存CTAボタンと同様に機能する
- [x] `npm run lint`・`npm run test`（新規コンポーネントのテストを含む）が通過する
