# #00069 プライバシーポリシー/利用規約画面のフッター・ヘッダーアンカーリンク不具合修正

- 対象リポジトリ: frontend
- ステータス: 完了
- type: fix
- 関連ドキュメント:

## 実現すること

`/privacy`（プライバシーポリシー）・`/terms`（利用規約）を表示中に、フッターの「特長」「使い方」「出題形式」を押下しても画面遷移が発生しない不具合がある。

原因: `SiteFooter`の`navLinks`が素の`<a href="#features">`のようなフラグメントのみのハッシュリンクになっている。フラグメントのみのhrefは「現在のパス+フラグメント」への同一ドキュメント内遷移として扱われるため、`/privacy`にいる状態でクリックすると`/privacy#features`になるだけでトップページ（`/`）へは遷移しない。トップページ上の該当セクション（`id="features"`等）は`/privacy`・`/terms`にはレンダリングされないため、要素が存在せずスクロールも発生しない。

`SiteHeader`にも全く同じ`navLinks`配列・同じ実装が重複定義されている。現状ヘッダーはトップページでしか描画されないため顕在化していないが、同一の潜在バグのため今回まとめて修正する。

修正方針:

- ヘッダー・フッターで重複定義されている`navLinks`を共通ファイルに切り出す
- hrefをフラグメントのみ（`#features`等）からルート絶対パス+フラグメント（`/#features`等）に変更する
- リンクの実装を素の`<a>`から、同ファイル内の`legalLinks`と同様のNext.js `<Link>`に統一する
