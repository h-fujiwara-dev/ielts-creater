# #00078 デプロイ済み環境の全削除

- 対象リポジトリ: root / frontend / backend / infra
- ステータス: 完了
- type: chore
- 関連ドキュメント: [docs/システム要件定義書.md](../docs/システム要件定義書.md)（8章 アーキテクチャ）

## 実現すること

ポートフォリオとしてデプロイしている全環境（AWS dev/prod、Vercel、Supabase）を削除し、運用コストと公開中のコンテンツをゼロにする。ドメイン`band-eight.com`（Cloudflare）と4つのGitHubリポジトリは残し、関連するDNSレコードとデプロイ用の設定のみ整理する。データのバックアップは取得しない。

## 受け入れ条件

- [x] Vercelプロジェクト`ielts-creater-frontend`を削除し、`band-eight.com` / `ielts-creater-frontend.vercel.app`が応答しないこと
- [x] AWS prod環境（`terraform/envs/prod`）を`terraform destroy`で削除する（事前にS3音声バケット・ECRイメージを空にする）
- [x] AWS dev環境（`terraform/envs/dev`）を`terraform destroy`で削除する（同上）
- [x] Terraform state外のSES email identityを削除する
- [x] Supabaseプロジェクトを削除する
- [x] tfstate基盤（`terraform/bootstrap`：S3・DynamoDB・GitHub OIDC Provider）を削除する
- [x] Cloudflare上の関連DNSレコード（apex・`auth`・ACM検証・SES DKIM・Resend関連）を削除する
- [x] GitHubのデプロイ用Variables / Environments（backend・frontend）を削除する
- [x] `aws resourcegroupstaggingapi get-resources --tag-filters Key=Project,Values=ielts-creater`で課金対象リソースが残っていないことを確認する
