# チケット管理

プロジェクト全体（root / frontend / backend / infra の4リポジトリ）のチケットをこのリポジトリで一元管理する。

## 運用ルール

1. 新規チケットは [`_template.md`](./_template.md) をコピーし、`XXXXX_タイトル.md`（5桁ゼロ埋めの連番）として作成する。番号はこのリポジトリ全体を通して一意（既存の最大番号の次を使う）
2. ステータスは「未着手」「進行中」「完了」の3段階。着手時に「進行中」、完了時に「完了」へ更新し、作業ログに日付を追記する
3. 1チケットは機能単位。複数リポジトリにまたがってよい（対象リポジトリに列挙する）
4. 作業対象の各リポジトリのコミットメッセージは `[#チケット番号] type: 概要` でチケットに紐づける（[各リポジトリのCLAUDE.mdのコミットメッセージ規則](../CLAUDE.md#コミットメッセージ規則)を参照）
5. チケット完了後もファイルは削除せず、このリポジトリの`tickets/`配下に残す（作業履歴として保持）
6. このREADMEにチケット一覧・番号は記載しない。個々のチケットは`tickets/`配下のファイルを直接参照する（`ls tickets/`で確認可能）。並行して複数チケットのブランチが作成されるため、一覧を都度更新する運用はコンフリクトの原因になりやすいため廃止した
