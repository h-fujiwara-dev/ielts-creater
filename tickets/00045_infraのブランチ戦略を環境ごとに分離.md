## 実現すること

`ielts-creater-infra`のTerraformは`terraform/envs/dev`（構築済み）と`terraform/envs/prod`（未構築）に既に分かれているが、ブランチ戦略は他3リポジトリと共通の「`develop`→`main`」の1系統のままで、Terraformの環境分離と対応していない。ロードマップPhase 3でprod環境構築が控えているため、`infra`リポジトリのみブランチを環境ごとに分離する。

```text
main ← develop ← 作業ブランチ   （dev環境向け、現状維持）
main ← prd     ← 作業ブランチ   （prd環境向け、新設）
```

`main`はdev/prd両系統からのリリースPRを受け入れる統合先として維持する。既存の`main`/`develop`はリネームせず、`prd`ブランチを新設する。この変更は`infra`リポジトリのみが対象で、root/frontend/backendの`develop`/`main`運用は変更しない。
